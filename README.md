## 📋 Deskripsi Proyek

Proyek ini adalah halaman web sederhana yang menampilkan profil anggota Kelompok 8 mata kuliah UI/UX. Halaman ini dibuat sesuai dengan contoh desain yang diberikan dalam materi perkuliahan.

### Fitur Utama

- ✅ Header dengan icon, judul, dan subjudul
- ✅ Intro section dengan card layout
- ✅ Grid kartu profil anggota (5 anggota)
- ✅ Layout responsif 2 kolom
- ✅ Foto profil masing-masing anggota
- ✅ Informasi biodata lengkap (Nama, NIM, Prodi, TTL, Hobi, Instagram)
- ✅ Footer dengan informasi hak cipta

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur halaman
- **CSS3** - Styling dan layout
- **Font Awesome** - Icon library
- **Google Fonts (Poppins)** - Font modern untuk UI yang lebih baik

## 🚀 Cara Menjalankan

1. Clone repository ini:
   ```bash
   git clone https://github.com/Budibudian17/tugaskuliahui-ux.git
   ```

2. Masuk ke folder proyek:
   ```bash
   cd tugaskuliahui-ux
   ```

3. Buka file `index.html` menggunakan browser:
   - Double-click file `index.html`
   - Atau drag-and-drop ke browser

- Memahami dasar struktur HTML
